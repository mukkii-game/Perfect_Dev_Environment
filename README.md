# Perfect Dev Environment — 作戦会議室

個人開発(主にブラウザゲーム、ほか役立つアプリ・ツール)のための「私に向いた究極の環境」を設計するプロジェクト。

この repo には **コードは入れない**。入るのは作戦・決定・進捗・調査情報だけ。
計画が固まったテーマから順に、別 repo(エンジン、ツール、テンプレート)、スキル、スプレッドシートとして実体化していく。作品は 1 本 1 repo。

## 今の状態(1行)

**2026-09-13: 会議室を開設。要件を 9 テーマに振り分け済み。テーマ 01(repo構成)・02(AIの作法)から詰める。10(学習マイルストーン)を追加。**

## 読む順番

| 目的 | 読むもの |
|---|---|
| 今の環境がどうなっているか 1 枚で知りたい | [STATUS.md](STATUS.md) |
| 何をどの順で決めていくか | [ROADMAP.md](ROADMAP.md) |
| テーマごとの検討内容 | [topics/](topics/) |
| 決まったことと理由 | [decisions/](decisions/) |
| 集めた情報の生データ | [research/](research/) |
| 日々の記録 | [progress/](progress/) |

## 会議室の運用ルール

- 各 topic は「現状の結論 / 検討中の論点 / 調べたこと / 次にやること」の 4 見出しで統一する。人間は「現状の結論」だけ読めば済むようにする。
- 何かが決まったら `decisions/YYYY-MM-DD-<題名>.md` を 1 枚書き、`STATUS.md` を同じコミットで更新する。
- 過去の記述は消さず、日付つきで「以前はこう、今はこう」と残す(特に AI モデルまわり)。
- 文書は日本語。将来のコード・コミットは英語。公開文は日英併記。
