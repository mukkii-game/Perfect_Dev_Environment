# 宣伝のテク(引くためのもの)

**作っただけでは誰にも知られない。** 公開と同時に、ここから使えるものを選ぶ。
一件ごとに出典を付ける。うまくいった例は**件数 1 の成功例**であって保証ではない。

最終確認: 2026-10-01

## A. プレスリリースを媒体へ送る(費用 0 円)

出典: [白米|Hakumai Studio「個人開発のスマホゲームのプレスリリースを約80媒体に送ったら、2時間後に記事になった話」](https://x.com/hakumai_studio/status/2105243127858823370)(2026-09-30)。
結果: 台湾の巴哈姆特 GNN に**送信から約2時間半で掲載**、韓国 GameFocus に約3時間で掲載。半日で新規約60人。
記者・編集者が書いたコツの記事を日英 50 本近く集めてから実行している。

| コツ | 中身 | うちでの対応 |
|---|---|---|
| **1. 事実を 1 枚の表に** | 配信日・価格・対応言語・数(仲間 48 種なら「約50」は可、「50以上」は不可)。リリース・ストア・プレスキットで数字がずれるのを防ぐ | **`publish.json` がこれ**。文面の唯一の置き場にしてある |
| **2. プレスキットを作る** | キービジュアル(ロゴ有無)、スクショ、**数秒の GIF**、紹介動画、開発者コメント、全部入り ZIP。言語ごとに | **公開キット(`/kit/`)がほぼこれ**。足りないのは GIF とロゴ・キービジュアル(→下の宿題) |
| **3. 件名を見出しの形に** | 「掲載のお願い」ではなく、そのまま記事の見出しに使える事実。大手には 1 日数百〜1000 通届く | 例:「【プレスリリース】個人開発の◯◯『タイトル』ブラウザで公開/作者名」 |
| **4. 冒頭に「すぐ試せる入口」** | 本文の最初の数行に「個人開発であること」「ブラウザならインストール不要」 | **ブラウザで遊べるのはうちの最大の強み**。必ず冒頭に書く |
| **5. 送り先は「小さな作品を実際に載せているか」で選ぶ** | 直近 1 年に個人開発・小規模作品の記事があるかを 1 媒体ずつ確認。大作ばかりの媒体には送らない。迷ったら送らない | 送り先リストを作る時に AI に確認させる |
| **6. 窓口は公式の「情報提供」「Contact」だけ** | お客さま窓口に送ると転送の手間をかける | |
| **7. 1 通ずつ、相手国の平日の朝に** | 一斉送信しない。宛名に媒体名。5 分ほど間隔。**台湾・韓国の朝一番が当日掲載につながった** | |
| **8. 本文に全文を貼る** | 添付ファイルにしない。画像はキービジュアルと GIF の 2 枚だけ添付。残りはプレスキットのリンク | |
| **9. 相手の言葉で送る** | 台湾は繁体字、韓国は韓国語。**送った繁体字の約 4 割がほぼそのまま記事に使われた**(翻訳の手間がない状態で届いた) | 今は日英のみ。**繁体字・韓国語を足すと東アジアに効く** |
| **10. 1 週間後に 1 回だけ再送** | 新しい情報を付けて | |
| **11. 掲載されたらプレスキットに「掲載記事」欄** | 後から見た記者への後押し | |

**失敗から(必読)**: AI に書かせた草案に**「即日掲載いただけます」「取り上げるかはお任せします」**と
偉そうな文が入っていた。**送る前に必ず人間が目を通す。** ここは自動化しない。

**AI に任せた範囲**: コツ記事の収集と要約、送り先候補の収集と「小さな作品を載せているか」の確認、
各言語への翻訳と言い回しの見直し、間隔をあけて送る道具。
**人間が決めた範囲**: どこに送るか、どんな言い方にするか、何を載せるか。80 件を 2 日で準備できた。

## B. SNS(X など)

| コツ | 出典 |
|---|---|
| 動画は撮り直さず、1 本を全配布先・全投稿に流用。静止画より動画の方が伸びる | Galaxtris の運用(tetrishoot/docs/RELEASE-KIT.md) |
| 最初の 1 行で「何のゲームか」を言い切る | 同上 |
| URL を本文に入れるとリーチが落ちる場合があるので、リプライにぶら下げる手もある | 同上(要検証) |
| X の自動投稿はブラウザ操作でやらない(**規約違反、凍結リスク**)。公式 API か RSS 連携 | 2026-09-18 のセカンドオピニオン(topics/05) |

## C. 宿題(うちの仕組みに足すもの)

- [ ] 公開キットに **数秒の GIF** を足す(`play.webm` から ffmpeg で切り出せる)
- [ ] 公開キットに **キービジュアル(ロゴ有無)と ロゴ単体** の欄を足す
- [ ] `publish.json` に **繁体字・韓国語** の欄を足せるようにする(翻訳は AI、確認は人間)
- [ ] プレスリリースの**ひな形**(件名・冒頭・事実表・プレスキットへのリンク)を公開キットから生成する
- [ ] 送り先の媒体リスト(国別・「小さな作品を載せるか」確認済み)を作る。**1 作品目で作れば以後使い回せる**
