# ゲームデザイン・データベース(genres/ と pieces.csv)

**目的**: どのジャンルを作る時も毎回調べ直さず、ジャンルをまたいで「ピース」を選んで組み合わせられるようにする。
Mukkii はあらゆるジャンルを 1 本ずつ作り、ジャンルのかけ合わせで新しさを出す(2026-10-12 方針)。

## 4 つの層
| 層 | 中身 | 置き場 |
|---|---|---|
| 0. 原理 | どのゲームにも効く抽象的な考え方(リスクとリターン、緩急、自分の手柄と感じさせる、期待させて裏切る…) | `../game-design.md` |
| 1. 大分類 | 似た遊びの大きなまとまり(手を動かし続ける系 / 止まって考える系 …)で共通するお約束 | `_families.md` |
| 2. ジャンル | そのジャンルのお約束・システム・データ構造・バランス・UI・素材・参考 URL | `<ジャンル>.md`(例 `shmup.md`) |
| 3. ピース | **場面ごとの具体的な仕掛け**: 「こういう時に、こうすると、こういう攻略・驚きが生まれる」 | `../tables/pieces.csv`(1 行 1 ピース。スプシ「開発ノウハウ一覧」のピースタブで絞り込める) |

上の層ほど抽象的、下ほど具体的。ピースは必ず「どの原理(0)を狙ったものか」と「他のどのジャンルに持ち出せるか」を書く。これがかけ合わせの手がかりになる。

## ピース(pieces.csv)の列
`ID, 大分類, ジャンル, 種類, 名前, こういう時, こうすると, こうなる, 狙う体験, 持ち出し先, 実例, 出典, 確かさ, うちで使った, わかった`
- **種類**: 仕掛け / 敵 / 地形・配置 / 操作 / 演出 / 報酬 / 難易度 / UI / 物語
- **こういう時**: 場面・状況(例: 「ステージ後半で、プレイヤーが自機狙い弾の避け方を覚えた頃」)
- **こうすると**: 置くもの・やること(例: 「自機狙いの弾と、ばらまき弾を同時に撃つ敵を出す」)
- **こうなる**: 生まれる攻略・判断・驚き(例: 「ちょん避けでは抜けられず、大きく切り返す判断が要る」)
- **狙う体験**: 層 0 の言葉(リスクとリターン / 緩急 / 読み / 自分の手柄 / 落差 / 習熟の確認 …)
- **持ち出し先**: 他のジャンルで同じ形が効く所(例: 「プラットフォーマーの動く足場 / タワーディフェンスの混成ウェーブ」)
- **確かさ**: 実測(うちの作品で確かめた)/ 定説(複数の出典)/ 一説(1 出典)
- ID の頭: `ALL`(全般)/ `ACT`(リアルタイム操作)/ `THK`(考えて選ぶ)/ `MNG`(育てて管理)/ `STO`(物語と探索)/ `SOC`(対人と協力)/ ジャンルの 1 枚から来たものは `PF` `PZ` `RL` `SH` など。
- スプシ「開発ノウハウ一覧」の**ピース**タブは、この CSV を IMPORTDATA で映している(1 行目のフィルタで、ジャンル・種類・狙う体験で絞れる)。書き込みは CSV へ。

## 使い方
- **新作を作る時**: 層 2 の 1 枚を読み、層 3 をジャンルと「持ち出し先」で絞って、使うピースを SPEC に 3〜10 個書く(ID で)。
- **かけ合わせ**: 2 つのジャンルのピースを並べ、「狙う体験」が同じものを 1 つのルールに合体させる(ひねりは要素を足さず合体させる。`../start-from-reference.md`)。
- 使ったピースは HANDOFF に `会議室: pieces <ID> / 効いた・効かなかった` と書く。毎晩の回収が「うちで使った」と確かさを直す。

## どう育つか(自動)
- **毎朝の収集**: ジャンルに効く話に「ジャンル: <名前>」を付ける。場面の具体的な仕掛けは「ピース候補」と書く。
- **毎晩の回収**: 「ジャンル: 」付きの知見は該当ファイルの節へ、「ピース候補」は pieces.csv へ 1 行。作品で確かめたら「実測」に上げる。
- **週次レビュー**: 作っている作品のジャンルの 1 枚が無ければ起こす(週 1〜2 枚。作った・作り始めた作品のジャンルが先)。pieces.csv の重複をまとめる。
- **ゲームデザインの講演・記事の要約の蓄積**(非公開の知識 repo、2,200 枚超): 毎晩 10 枚ずつ、具体例のあるものをピースに直して足す。公開の会議室には自分の言葉で要約し、出典は元の講演名で書く。

無いジャンルの作品を始める時は、作品セッションが `_template.md` の節立てでその場で 15 分下調べして SPEC に書き、
「会議室: genres/<ジャンル> / 無かった」を HANDOFF に残す。
