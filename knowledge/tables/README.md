# 人間向けの一覧表(原本)

**ここの CSV が原本。** スプレッドシート「[開発ノウハウ一覧](https://docs.google.com/spreadsheets/d/1dGxievZAel7hJ6oF-sQPVIatn2AtWc6_epV8Qo7srDs/edit)」(Drive)はこれを `IMPORTDATA` で読んで表示するだけ(リンク固定・自動で最新。初回だけ「アクセスを許可」が要る)。

| ファイル | 中身 |
|---|---|
| `ai.csv` | AI の表(特徴・利点・欠点・ランク・使う場面) |
| `assets.csv` | **道具の総合表**(素材・制作道具・ライブラリ・公開手続き)。上位の **分野**(絵/音/3D/映像/文字/コード/公開・手続き)と **工程**(入手/作る/加工/組む/確かめる/出す)で並ぶ |
| (`libraries.csv` は assets.csv に統合して削除) |
| `mindset.csv` | **人間の心構え・頼み方・確認のチェックリスト**(AI 駆動開発) |
| `genres.csv` | **ゲームジャンル別の作法**と、相性の良いエンジン・素材、AI で自動検証しやすいか、1日1本向きか |

- **区分**: 優先(よく使う第一候補) / 条件付き(場面によって使う) / 外した / 使えない
- **AI操作**: ◎ AIだけで完結 / ○ MCP・API で AI が操作できる / △ 人間の手が要る(それでも使う価値があるものだけ載せる)
- **方針**: 同じことができるなら ◎ > ○ > △。Adobe 全部入りを契約しているので、Adobe で足りるものは Adobe を優先
- ランク: **S** 迷ったらこれ / **A** 場面が合えば第一候補 / **B** 補助 / **C** ほぼ使わない / **外した** / **—** 使えない・保留
- 詳しい理由・出典は同じフォルダの上の md(`catalog-tools.md`、`ai-models.md`、`engines.md`)。md を直したら CSV も直す。
- 人間が直接直したら(GitHub 上で CSV を編集、または会議室に「こう変えた」と連絡)、次に会議室が md 側へ反映する。
- スプレッドシート側で直接書き換えても**原本には戻らない**(次の読み込みで消える)。直すなら CSV か、会議室に一言。

2026-10-03: ユーザーの旧メモ(Google スプレッドシート「ゲームのノウハウ」の AI・ツール・ジャンルのタブ)から、今も使えるものだけ移した。
Unity 専用アセット・古い AI(o1、Claude 3.5 等)・個人の PC 設定は捨てた。

## 更新の流れ
- 毎朝の収集: 新しい道具・モデルを「一覧表に足す候補」としてドライブの日報に挙げる(表はまだ変えない)
- 毎週月曜の週次レビュー: 1 週間分の候補を見て、足す・ランクを変える・外すを実際に行い、ai.csv はWeb検索で最新化する
- 作品で実際に使って分かったことは、その日に会議室で直す(使用実績が一番強い根拠)
