# 人間向けの一覧表(原本)

**ここの CSV が原本。** スプレッドシート「[開発ノウハウ一覧](https://docs.google.com/spreadsheets/d/1hhdZWzwnUna2WfvQDEJsaU7h2TZUxBQAZheE9I9aaTE/edit)」(Drive)はこれを `IMPORTDATA` で読んで表示するだけ(リンク固定・自動で最新。初回だけ「アクセスを許可」が要る)。

| ファイル | 中身 |
|---|---|
| `ai.csv` | AI の表(特徴・利点・欠点・ランク・使う場面) |
| `assets.csv` | 素材と制作道具(画像生成・画像編集・デザイン・3D・SE・BGM・声・映像・フォント)。Adobe・Canva もここ |
| `libraries.csv` | エンジン・ライブラリ |

- **区分**: 優先(よく使う第一候補) / 条件付き(場面によって使う) / 外した / 使えない
- **AI操作**: ◎ AIだけで完結 / ○ MCP・API で AI が操作できる / △ 人間の手が要る(それでも使う価値があるものだけ載せる)
- **方針**: 同じことができるなら ◎ > ○ > △。Adobe 全部入りを契約しているので、Adobe で足りるものは Adobe を優先
- ランク: **S** 迷ったらこれ / **A** 場面が合えば第一候補 / **B** 補助 / **C** ほぼ使わない / **外した** / **—** 使えない・保留
- 詳しい理由・出典は同じフォルダの上の md(`catalog-tools.md`、`ai-models.md`、`engines.md`)。md を直したら CSV も直す。
- 人間が直接直したら(GitHub 上で CSV を編集、または会議室に「こう変えた」と連絡)、次に会議室が md 側へ反映する。
- スプレッドシート側で直接書き換えても**原本には戻らない**(次の読み込みで消える)。直すなら CSV か、会議室に一言。
