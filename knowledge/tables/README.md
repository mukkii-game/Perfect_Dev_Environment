# 人間向けの一覧表(原本)

スプシにする時の決まり(縦中央・折り返し・列幅・コメント欄)は `knowledge/sheet-style.md`。作るのは `tools/build-sheet.py`。

**ここの CSV が原本。** スプレッドシート「[開発ノウハウ一覧](https://docs.google.com/spreadsheets/d/1L3i02WVyMPxC-_wEiy1zSnyVFsCBHfRrrD25sXJVQAg/edit)」(Drive)はこれを `IMPORTDATA` で読んで表示するだけ(リンク固定・自動で最新。初回だけ「アクセスを許可」が要る)。

| ファイル | 中身 |
|---|---|
| `ai.csv` | AI の表(特徴・利点・欠点・ランク・使う場面) |
| `assets.csv` | **道具の総合表**(素材・制作道具・ライブラリ・公開手続き)。上位の **分野**(絵/音/3D/映像/文字/コード/公開・手続き)と **工程**(入手/作る/加工/組む/確かめる/出す)で並ぶ |
| (`libraries.csv` は assets.csv に統合して削除) |
| `storage.csv` | **どこに何を置いているか**(GitHub・ドライブ・Claude・手元PC) |
| `automations.csv` | **自動・半自動で動いているものの一覧**(定期実行・Actions・スクリプト)。いつ・どこで・何を・止まったらどう気づくか |
| `rules.csv` | **AI への指示(お作法)の一覧**。どのファイルが毎回読まれ、何行で、何が書いてあるか |
| `used-assets.csv` | **実際に作品で使った素材**(画像・SE・BGM・フォント等)。各作品の CREDITS.md を毎晩集める。★ が付いたものが「また使いたい」リスト |
| `learning/*.csv` | **Mukkii 育成プログラム**(別のスプシ)。カリキュラム・進捗・テスト・修了チェック・関連リンク。運用は topics/10 |
| `procedures.csv` | **公開・販売の手続き**(itch.io・Steam・BOOTH・DLsite・ストア等)の順番と要るもの。「要確認」は週次レビューが 2 行ずつ確かめる |
| `mindset.csv` | **人間の心構え・頼み方・確認のチェックリスト**(AI 駆動開発) |
| `tips.csv` | **AI の TIPS**(日々増える小さな知見)。毎晩の回収が AI知見の日報から最大 3 件足し、週次レビューが整理する(重複を統合、定着したものは心構え・カタログへ昇格して消す) |
| `glossary.csv` | **用語集**(AI・モデル・道具・仕組みの名前)。一言で・使い所・うちでは・詳細リンク。新しい名前が出たら足す(毎晩の回収・週次レビュー) |
| `genres.csv` | **ゲームジャンル別の作法**と、相性の良いエンジン・素材、AI で自動検証しやすいか、1日1本向きか |

- **区分**: 優先(よく使う第一候補) / 条件付き(場面によって使う) / 外した / 使えない
- **AI操作**: ◎ AIだけで完結 / ○ MCP・API で AI が操作できる / △ 人間の手が要る(それでも使う価値があるものだけ載せる)
- **方針**: 同じことができるなら ◎ > ○ > △。Adobe 全部入りを契約しているので、Adobe で足りるものは Adobe を優先
- ランク: **S** 迷ったらこれ / **A** 場面が合えば第一候補 / **B** 補助 / **C** ほぼ使わない / **外した** / **—** 使えない・保留
- 詳しい理由・出典は同じフォルダの上の md(`catalog-tools.md`、`ai-models.md`、`engines.md`)。md を直したら CSV も直す。
- 人間が直接直したら(GitHub 上で CSV を編集、または会議室に「こう変えた」と連絡)、次に会議室が md 側へ反映する。
- スプレッドシート側で直接書き換えても**原本には戻らない**(次の読み込みで消える)。直すなら CSV か、会議室に一言。

2026-10-03: ユーザーの旧メモ(Google スプレッドシート「ゲームのノウハウ」の AI・ツール・ジャンルのタブ)から、今も使えるものだけ移した。
Unity 専用アセット・古い AI(o1、Claude 3.5 等)・個人の PC 設定は捨てた。

## 更新の流れ
- 毎朝の収集: 新しい道具・モデルを「一覧表に足す候補」としてドライブの日報に挙げる(表はまだ変えない)
- 毎週月曜の週次レビュー: 1 週間分の候補を見て、足す・ランクを変える・外すを実際に行い、ai.csv はWeb検索で最新化する
- 作品で実際に使って分かったことは、その日に会議室で直す(使用実績が一番強い根拠)

## 素材庫(使った素材の手元保存)
- 場所: Google ドライブの非公開フォルダ「素材庫」(デスクトップでは G: から見える。クラウドの AI もドライブ経由で読める)
- **ファイルと一緒に、その時点の規約ページ(スクショか PDF)を同じフォルダに保存**する。配布元が消えたり規約が変わっても、使った時の条件が残る

- ★ が付いた素材から優先して保存する(全部は保存しない)

## わかったチェックと「値で書くタブ」(2026-10-06)
スプシの **AI・心構え・TIPS・用語集** の 4 タブは IMPORTDATA ではなく**値で書いてある**(並べ替え・絞り込みができ、☑ が行と一緒に動くように)。原本は今までどおり CSV。
- 各タブの「わかった(☑)」は Mukkii が付ける。CSV 側は最後の列「わかった」に「✓ YYYY-MM-DD」で記録する。
- 出典・詳細の URL は CSV に生で持ち、スプシでは `=HYPERLINK(url,"リンク")` で見せる(相対パスは会議室の GitHub URL を前につける)。

**同期の手順**(毎晩の回収が、CSV を変えた日と ☑ が増えた日に行う):
1. スプシの 4 タブを get_values で読み、☑ が TRUE の行を 1 列目(TIPS は「TIPS」列)で CSV の行と突き合わせ、CSV の「わかった」が空なら「✓ 今日の日付」を書く。☑ を外した行は CSV の ✓ を消す。
2. CSV を commit・push する。
3. **毎晩は足すだけ**: 新しい行は、1 列目を get_values で読んで最後の行を数え、その次の行に update_formulas で書く(☑ は FALSE)。**append_values は使わない**(チェックボックスが 300 行目まで入っているので 301 行目に足されてしまう)。全体の書き直しはしない(行数が増えるほどトークンを食うため)。読むのも ☑ 列と 1 列目だけにする。
4. **全体の書き直しは週 1**(週次レビューの整理で行を統合・削除した時だけ): batch_clear_values で消し、CSV から update_formulas で書き直す(わかった列は CSV の ✓ で TRUE/FALSE、コメントは元の行に戻す)。書き直したらチェックボックスの入力規則と、1 行目のフィルタ(setBasicFilter)を付け直す。
