# 公開先(引くためのもの)

**今は Web(ブラウザ)が主戦場。** Steam・Switch 2 は「まだ先」だが、**エンジン選びに効く**ので
今のうちに条件を書いておく(作ってから「このエンジンでは出せない」と分かるのが最悪)。

最終確認: 2026-10-01。**料金・審査・規約は変わる。出す前に必ず現地で確認する。**
(印のない行は会議室 AI の知識。私の知識は 2026 年 6 月まで)

## いま使っている公開先(Web)

| 公開先 | 自動化 | 状態 | 詳細 |
|---|---|---|---|
| GitHub Pages | **全自動**(push で公開) | 稼働中 | 雛形に組み込み済み |
| itch.io | **全自動**(butler) | 稼働中 | `publish-itch.yml` |
| PLiCy / ふりーむ! / Newgrounds | **半自動**(公開キットで素材と文面を揃え、人間が上げる) | 運用中 | クラウドからの自動投稿は不成立と確定(topics/05) |
| X | 公式 API か itch.io RSS 連携(予定) | 未着手 | ブラウザ自動操作は規約違反 |

## まだ先: Steam

| 項目 | 中身 |
|---|---|
| 登録料 | Steam Direct で **1 作品ごとに 100 米ドル**。売上が一定額に達すると返ってくる |
| 待ち期間 | 登録料を払ってから公開できるまで**一定の日数**がかかる。ストアページは公開前に**一定期間「近日公開」で出しておく**必要がある |
| 作るもの | **デスクトップ向けの実行ファイル**。ブラウザゲームはそのままでは出せない(Electron 等で包むか、Godot などで書き出す) |
| 効く宣伝 | **ウィッシュリスト**(公開前に溜める)。Steam Next Fest(体験版の祭り) |
| エンジンとの相性 | Godot・Unity・Unreal はどれも書き出せる。Web 製は包む手間がかかる |
| 向く作品 | 1 日 1 本のパイロットではなく、**反応が良かったものを作り込んだ後** |

## まだ先: Nintendo Switch 2

| 項目 | 中身 |
|---|---|
| 入口 | 任天堂の開発者登録(**審査あり**)。承認されると開発機材と資料が手に入る |
| 年齢区分 | CERO(日本)/ IARC 等の審査が要る |
| **エンジンとの相性(重要)** | **Unity と Unreal は公式に対応**。**Godot は公式には書き出せず、移植を請け負う会社や有料サービスを経由する**(要確認: 2026 年時点の状況)。**Web 製は出せない** |
| 向く作品 | Steam で手応えがあった作品の次の段 |

### Switch 2 を視野に入れるなら(エンジン選びへの影響)

**Switch に出す可能性が少しでもある作品は、最初から Unity か「移植の当てがある Godot」で作る。**
Web(JS)で作ると Switch には持って行けず、作り直しになる。
ただし今は 1 日 1 本の段階なので、**この判断が要るのは「これは作り込む」と決めた時だけ**。
→ `engines.md` の Godot / Unity の行とあわせて見る。
