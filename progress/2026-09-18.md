## 追記: ふりーむ! も不可。ただし解決策はある
- ふりーむ! も失敗。4 サイトすべてクラウドからは通らない
- ユーザーの指摘を受けて整理: **塞がっているのはクラウドだけ**。原因は IP であって道具ではない
- **本命の解決策: 自宅に GitHub Actions の self-hosted runner を置く**
  - 操作はスマホから今まで通り。実行だけ自宅で起き、住宅回線の IP で外に出る
  - Raspberry Pi なら常時稼働で月 100 円以下。「デスクトップを付けっぱなしにしたくない」を満たす
  - 書いたスクリプトはそのまま使える

## セカンドオピニオン(GPT / Gemini)で方針を修正
両者が独立に同じ結論に収束。会議室の見立てを 3 点修正した。
1. 原因を IP に寄せすぎた。失敗の種類が違うものを一括りにしていた
2. 自動操作ブラウザ自体が検知される(TLS/CDP のフィンガープリント)。IP を変えても残る
3. X のブラウザ自動化は「グレー」ではなく明確な規約違反。凍結リスクがある

**確定した方針**: 基本は半自動。X は公式 API か itch.io の RSS→OAuth 連携。機器購入は最後。
VPS とプロキシは却下。self-hosted runner は「本命」から「検証後の候補」へ降格。

**採用した新案**: スマホ用の公開キット / Tampermonkey ユーザースクリプト /
itch.io RSS → 外部連携で X 告知 / 新規登録と更新の分離

## 公開キットを作って動かした

Galaxtris で実装 → push → Pages に反映。<https://mukkii-game.github.io/tetrishoot/kit/>

- ZIP(18 ファイル 1.8MB)・スクショ 4 枚・プレイ動画 35 秒を CI が毎回そろえる
- 5 配布先(itch.io / PLiCy / ふりーむ! / Newgrounds / X)のリンクと注意書き
- 日英 7 種の文面にコピーボタン。X の `{{URL}}` は入力した公開 URL に自動差し替え
- 配布先ごとの状態と公開 URL を端末に保存(二重投稿を防ぐ)

設計は publish.json 1 枚に寄せてあるので、他のゲームへは 3 ファイルの複写で済む。
