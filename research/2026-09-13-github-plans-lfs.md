# GitHub の料金枠と LFS(2026-09-13 時点の理解、要再確認)

要点 3 行:
- ルールセット無しで失う自動化は無い。1 人開発なら不要。
- Actions は private でも無料枠(月 2,000 分)で 1 日 1 本のビルドは余裕。public は無制限。
- LFS は無料枠が小さく(1GB 保存 + 月 1GB 転送)、CI のクローンでも転送量を食う。Web 作品は Drive で代用できる。

## ルールセットが要る場面 / 要らない場面

| 場面 | 要否 |
|---|---|
| 1 人で main に直 push、Actions でビルド・公開 | 不要 |
| AI が壊した main を戻す | 不要(git revert / reset で戻る) |
| 「CI が通らないとマージさせない」を強制したい | 必要 |
| 複数人、外部コントリビュータ、製品の本番ブランチ | 必要 |

## プラン比較(個人)

| | Free | Pro(月 $4 ≒ 600 円) |
|---|---|---|
| Actions 無料分(private) | 2,000 分/月 | 3,000 分/月 |
| Actions(public) | 無制限 | 無制限 |
| Pages | public のみ | private でも可 |
| ルールセット | public のみ | private でも可 |
| Packages / Actions ストレージ | 500MB | 2GB |

1 日 1 本のビルド(数分)なら Free の private でも月 150 分程度。Pro が要るのは「private 作品を Pages で公開したい」時だけ。ユーザーは月 1,000 円程度なら払う意向。

## LFS(Git Large File Storage)

- 無料: 保存 1GB + 転送 1GB/月。追加は「データパック」1 つ月 $5 で保存 50GB + 転送 50GB。
- 落とし穴: **転送量はクローンのたびに消費**。Actions が毎回クローンすると、1GB のアセットを持つ repo は 1 日 1 ビルドで月 30GB。パック 1 つでも足りるが、無料枠は即枯れる。
- Drive で代用: **Web 作品なら可**。画像・音は Drive(または無料の静的ホスティング)に置き、ビルド時にスクリプトで取得するか、実行時に URL で読む。repo は軽いまま。
  代用できないのは Unity / UE のようにプロジェクト自体が巨大バイナリを含む場合。その段階の選択肢: (a) LFS データパック月 $5、(b) プロジェクト丸ごと Drive に置き Git はスクリプト類だけ、(c) LFS 無料枠の大きい別ホスティング。決めるのはその時でよい。
