# 16. 試運転: 惑星の庭師(hoshi-niwashi)

憲法・雛形・会議室の資料が、新しい作品で本当に効くかを確かめる。作り終えたら Claude がポストモーテムを書く。

## SPEC(作品 repo の SPEC.md にそのまま入れる)
- タイトル: 惑星の庭師
- 一言で: 四方から曲がって降ってくる隕石を、重力の点で寄せ集めてぶつけ、まとめて消す。
- 参考(◯◯みたいな): ミサイルコマンド(先を読んで置く、という骨組みだけ)
- ひねり(ウリ):
  - 置くのは爆弾ではなく、重力の点。隕石は惑星の重力で曲がり、渦を巻いて飛ぶ。
  - 隕石を寄せ集めてぶつけ合わせると、連鎖で消える。
  - 大きく集めた塊は月になって惑星のまわりを回り、盾になる。
  - 画面は惑星が真ん中にある円形。
- 操作: タップした場所に重力の点を置く。同時に置けるのは3つまで。置いた点は数秒で消える。PC はクリック。
- 勝ち / 負け / 終わり: 惑星の庭(HP)が尽きたら終わり。波を越えるほど隕石が増える。スコアを競う。
- 絶対に守ること: ミサイルコマンドのクローンに見えないこと。名前・絵・画面の配置を似せない。
- 任せ方: おまかせ
- 追加で読むルール: (なし)
