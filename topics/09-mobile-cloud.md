## クラウドセッションと GitHub の連携(2026-09-16)

新規セッションで「GitHub と連携」を求められる件。別の仕組みではなく、同じ仕組みの初回許可。

- 経路は 2 本。**git**(クローン・push。public は無許可で読める、private と push は資格情報が要る)と **GitHub API**(Issue / PR / Actions / secret。これが連携を求める相手 = Claude の GitHub アプリ)。
- 新セッションで聞かれるのは「どの repo から始めるか」と、未許可 repo の追加許可。
- **連携画面では "All repositories" を選ぶ。** 個別選択にすると、**新しく作った作品 repo を毎回手で許可し直す**ことになり、1 日 1 本の運用と噛み合わない。
- 連携を使わない代替: (a) 個人アクセストークンを環境変数に置いて素の git を使う(ai-ops がこの方式)、(b) すべて GitHub Actions 側で動かす(repo 自身の権限で動くので外部連携が不要)。どちらも手間が増えるので、強い権限が要る時だけ。
- セッション中に repo を足す時は `add_repo` で足せる(このセッションで実施済み)。会議室から作品 repo を触る時はこれを使う。
