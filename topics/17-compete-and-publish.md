# 17. 勝ち筋: 星野創吉さんを基準に、真似る所と上回る所(2026-10-07 起案)

## 相手の今の強み(確認した範囲)
- AI 社員の運用(Claude Code で 5 本部・13 部署・46 体と本人談)と、その見せ方。
- X の長文記事が伸びる(dots の記事: 表示 14.6 万・ブックマーク 568)。型は「悩みの言い当て → 常識を疑う → 手順 → 安全の線引き → 今日やる 1 つ → 誘導」。
- **ゲームは作っていない**(調べた範囲で見つからない)。土俵は「AI で仕事を回す」と「X で伸ばす」。

## 真似る所
- 伸びる記事の型(上の流れ)。毎朝の収集で、伸びた投稿の型を記録して溜める(sources.md で競合として観察)。
- 「AI 社員」の見せ方。うちの実物(毎朝の収集・追いかける係・夜の回収・週次レビュー・雛形)は既に「AI 開発部隊」なので、数と役割を見える形にして発信の種にする。
- 「AI が止まる線」を先に書く安全設計(うちも決めてある。ゾーン A/B/C)。

## 上回る所(プロとして負けない所)
- **面白さの深さ・バリエーション・ユニークさ**。相手は作品を出していない。こちらは「毎日 1 本、毎回ひねりがある」実物で勝負する。
- そのための仕組み: SPEC の「ひねり」欄 / 元ネタは床 / 面白さは人間が早めに触る / 失敗の記録(おばけ提灯)/ 合格条件に「気持ちいい瞬間」を 1 行。
- 発信は「作った物 + どう作ったか」をセットにする(相手にはできない組み合わせ)。
