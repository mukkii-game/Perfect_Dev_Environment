# 16. 試運転: おばけ提灯(obake-chochin)

憲法・雛形・会議室の資料が、新しい作品で本当に効くかを確かめる。作り終えたら Claude がポストモーテムを書く。

## SPEC(作品 repo の SPEC.md にそのまま入れる)
- タイトル: おばけ提灯
- 一言で: 夜の村に寄ってくるおばけを提灯でおびき寄せて集め、割ってまとめて成仏させる。
- 参考(◯◯みたいな): ミサイルコマンド(先を読んで置く、という骨組みだけ)
- ひねり(ウリ):
  - おばけはまっすぐ来ない。ふらふら漂うもの、ジグザグに進むもの、急に跳ぶもの、光を嫌うものがいる。
  - 置くのは爆弾ではなく提灯。おばけは提灯に寄って集まる。
  - 提灯は2回目のタップで割れる。たくさん溜めてから割ると連鎖で成仏し、大きなカタルシスになる。
  - 成仏したおばけが一時的に味方の灯りになる、など「敵を利用する」要素を入れる。
- 見た目と配置: 和の夜。村は画面の下ではなく、横長の巻物の中ほどに家々が点在する配置。ミサイルコマンドの「下に基地が並ぶ」画面にしない。
- 操作: タップで提灯を置き、もう一度タップで割る。同時に置けるのは3つまで。PC はクリック。
- 勝ち / 負け / 終わり: おばけが家に入ると灯りが消える。全部消えたら終わり。夜が更けるほどおばけが増える。スコアを競う。
- 絶対に守ること: ミサイルコマンドのクローンに見えないこと。名前・絵・画面の配置を似せない。
- 任せ方: おまかせ
- 追加で読むルール: (なし)
